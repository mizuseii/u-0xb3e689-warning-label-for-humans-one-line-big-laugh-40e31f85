A one-line safety warning label for humans, in the form of a real printed product label: "WARNING: Contents under pressure. May explode if told to calm down, then apologize by doing the dishes very loudly." It takes the familiar label opening and lands the laugh on a universal human truth — being told to calm down never calms anyone down.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=./out node --experimental-strip-types main.ts
```

This writes the 115-character entry line to `out/entry.txt` (no trailing newline), deterministically and offline.
